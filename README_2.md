# charm-themes  Unified theming system for [charmbracelet](https://github.com/charmbracelet) libraries.  Define a color palette once, use it everywhere ÔÇö lipgloss, glamour and bubbles.  > **[Leia em Portugu├¬s (PT-BR)](README.pt-br.md)**  ## The Problem  Each charmbracelet library has its own styling system: - **lipgloss** uses `lipgloss.Style` with inline color definitions - **glamour** uses a `StyleConfig` with JSON or Go structs - **bubbles** components each have their own `Styles` struct  When building a TUI app, you end up defining the same colors 3+ times in different formats. Changing your theme means updating every single style definition.  ## The Solution  ```go import (     "fmt"      "charm.land/lipgloss/v2"      themes "github.com/junhinhow/charm-themes" )  // Pick a theme theme := themes.Gruvbox  // Use with lipgloss ÔÇö call it once and reuse the result styles := theme.Lipgloss() fmt.Println(styles.Title.Render("Hello")) fmt.Println(styles.Error.Render("Something went wrong")) fmt.Println(styles.Border.Render("Boxed content"))  // Use semantic colors directly myStyle := lipgloss.NewStyle().     Foreground(theme.Primary).     Background(theme.Background) ```  ## Install  ```bash go get github.com/junhinhow/charm-themes ```  ## Built-in Themes  | Theme | Background | Primary | Accent | |-------|-----------|---------|--------| | **Gruvbox** | `#282828` | `#fabd2f` | `#83a598` | | **Dracula** | `#282a36` | `#bd93f9` | `#ff79c6` | | **Nord** | `#2e3440` | `#88c0d0` | `#b48ead` | | **Catppuccin** | `#1e1e2e` | `#cba6f7` | `#f5c2e7` | | **Tokyo Night** | `#1a1b26` | `#7aa2f7` | `#bb9af7` |  ## Looking up themes  ```go // Lookup by name (case insensitive) theme, ok := themes.Get("tokyo-night") if !ok {     // no such theme }  // All themes, indexed by name all := themes.Themes()  // Names in a deterministic (alphabetical) order names := themes.ThemeNames() ```  `Themes()` and `Get()` return **copies** of the built-in themes, so customizing the returned value never corrupts the package-level themes (`themes.Nord`, `themes.Gruvbox`, ÔÇª).  ## Theme Structure  ```go type Theme struct {     Name       string     Background color.Color     Foreground color.Color     Primary    color.Color  // headings, titles     Secondary  color.Color  // subtitles, secondary info     Accent     color.Color  // highlights, emphasis     Success    color.Color  // green/positive     Warning    color.Color  // yellow/caution     Error      color.Color  // red/negative     Info       color.Color  // blue/informational     Muted      color.Color  // gray/disabled     Syntax     SyntaxColors // code highlighting } ```  ## Validation  A hand-built theme may be missing colors. `Validate()` reports every missing role instead of silently rendering without color:  ```go if err := theme.Validate(); err != nil {     return err }  // The syntax colors can be validated on their own if err := theme.Syntax.Validate(); err != nil {     return err } ```  ## Lipgloss Styles  ```go styles := theme.Lipgloss()  styles.Base        // plain text styles.Bold        // bold styles.Italic      // italic styles.Faint       // faint  styles.Success     // success message styles.Warning     // warning styles.Error       // error styles.Info        // info  styles.Title       // title (primary, bold) styles.Subtitle    // subtitle (secondary) styles.Highlight   // highlight (accent, bold) styles.Border      // rounded border box styles.Code        // inline code ```  > `Lipgloss()` builds 13 `lipgloss.Style` values on every call. Call it **once** during > initialization and reuse the result ÔÇö calling it inside the render loop wastes allocations.  ## Glamour Integration  `Glamour()` returns a `glamour/ansi.StyleConfig` derived from the theme, including a Chroma configuration for code blocks:  ```go import "charm.land/glamour/v2"  renderer, err := glamour.NewTermRenderer(glamour.WithStyles(theme.Glamour())) if err != nil {     return err }  out, err := renderer.Render("# Hello\n") ```  The convenience method `GlamourRenderer()` does both at once and accepts extra options:  ```go renderer, err := theme.GlamourRenderer(glamour.WithWordWrap(100)) ```  ## Bubbles Integration  `Bubbles()` returns the styles of the most common bubbles components, ready to be applied to the components:  ```go styles := theme.Bubbles()  styles.List       // list component styles.Table      // table component styles.TextInput  // textinput component styles.TextArea   // textarea component styles.Help       // help component  // The list exposes its styles as a public field... l := list.New(items, list.NewDefaultDelegate(), 80, 24) l.Styles = styles.List  // ...while the other components use SetStyles. t := table.New(table.WithColumns(columns)) t.SetStyles(styles.Table) ```  > Just like `Lipgloss()`, `Bubbles()` builds every style from scratch on each call. Call > it **once** and reuse the result.  ## Roadmap  - [x] lipgloss integration - [x] glamour integration (StyleConfig + Chroma) - [x] bubbles integration (list, table, textinput, textarea, help) - [ ] huh integration (forms) -
