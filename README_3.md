# charm-themes  Sistema de temas unificado para as bibliotecas [charmbracelet](https://github.com/charmbracelet).  Defina uma paleta de cores uma vez, use em todos os lugares ÔÇö lipgloss, glamour e bubbles.  > **[Read in English](README.md)**  ## O Problema  Cada biblioteca charmbracelet tem seu pr├│prio sistema de estilos: - **lipgloss** usa `lipgloss.Style` com cores inline - **glamour** usa uma `StyleConfig` com JSON ou structs Go - **bubbles** cada componente tem seu pr├│prio struct `Styles`  Ao construir um app TUI, voc├¬ acaba definindo as mesmas cores 3+ vezes em formatos diferentes. Mudar o tema significa atualizar cada defini├º├úo de estilo.  ## A Solu├º├úo  ```go import (     "fmt"      "charm.land/lipgloss/v2"      themes "github.com/junhinhow/charm-themes" )  // Escolha um tema theme := themes.Gruvbox  // Use com lipgloss ÔÇö chame uma ├║nica vez e reutilize o resultado styles := theme.Lipgloss() fmt.Println(styles.Title.Render("Ol├í")) fmt.Println(styles.Error.Render("Algo deu errado")) fmt.Println(styles.Border.Render("Conte├║do em caixa"))  // Ou use as cores diretamente em estilos customizados myStyle := lipgloss.NewStyle().
